Update the download

  1. On GitHub, remove the old FinBud-original-debug.apk asset.
  2. Choose the new APK file and name it FinBud-original-debug.apk.
  3. Select Update release.

Keep the asset name and release tag the same. The public download button will then point to the new APK automatically.
